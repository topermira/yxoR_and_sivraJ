# \## Как сливали

# 

# Каждый работал в своей ветке, а в `main` всё попадало через слияние.

# 

# \- \*\*Ветки `top1`, `top2`, `top3`\*\* создали от `main` и слили командой `git merge --no-ff`. Этот флаг заставляет Git сделать отдельный коммит слияния. Так в истории видно, какая ветка и когда попала в `main`.

# \- \*\*Почему не rebase.\*\* `rebase` переписывает коммиты ветки, а ветки уже отправлены на GitHub и с ними работает второй участник. Переписывать то, что уже на GitHub, и тем более то, с чем работает другой человек, нельзя.

# \- \*\*Ветки Арсения\*\* пока не слиты, потому что в них не все решения. Когда он их доделает, `arseniy1` и `arseniy2` дадут конфликт в файлах `PY\_9\_17.ipynb` и `PY\_9\_18.ipynb`: Git не знает, чью версию оставить. Конфликт нужно разрешить вручную, сохранив решения обоих.
